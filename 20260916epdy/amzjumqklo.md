# 是孕冻，还是要孕动?

> 更新时间：2026-09-16 (UTC+8)

「媳妇，不要乱动，小心动了胎气，家事由我来做」，「老婆，这个不要提，我来拿」，「恭喜，怀孕了，妳的工作我来帮妳调轻松一点」…，不管是婆婆、先生还是老板，传统观念怀孕后要多休息，对于运动、提重、工作、家事、逛街等日常作息通通要减少，甚至要避免。然而，减少日常活动量或避免体育活动，对胎儿或对妈妈的健康有帮助吗? 还是适得其反? 科学的研究及建议又是如何呢?

运动的好处，大家都很清楚，包括减少心血管疾病、中风、糖尿病、部分癌症发生，及改善心智健康等。因此，世界卫生组织在2010年发表“促进健康的体育活动：全球建议”：针对18至64岁成年人，应鼓励每周至少150分钟的中等强度有氧运动或75分钟的剧烈强度有氧运动，及每周2次以上的肌力训练。
运动对于女性的生殖功能，也很有帮助，尤其是多囊卵巢综合症患者；对于接受试管婴儿胚胎移植的妇女，维持日常活动者，成功怀孕率也较高；对于已怀孕的妇女，因身体特殊变化，需有特别考虑。
 
怀孕的身体变化
妇女怀孕期间，身体会随着孕期而产生变化，身体变化及运动考虑如下：
1. 心跳速率增加，心脏血流输出增加，换气增加，生理性贫血：怀孕期间，心肺负荷增加，并容易有姿势改变的低血压及晕眩，因此，针对孕妇运动的强度及种类，须有所调整，应避免过度运动，如竞赛等，也应避免久站，以免影响血液循环。
2. 怀孕期间贺尔蒙改变，关节韧带会较松弛：须注意运动伤害，应避免过度伸展运动。
3. 背负着胎儿的大肚子：怀孕中后期，子宫长大突出于外，应避免易跌倒或冲撞的运动。另外，平躺时，子宫会压迫下腔静脉，影响血液回流至心脏，怀孕16周以后，避免平躺姿势的运动。
4. 热量需求增加：运动前后，适度补充饮食及水分。
因此，怀孕期间运动建议，须根据孕妇个别的状况而订定，也须随怀孕周数而有所调整。
 
运动对胎儿及怀孕的影响
1. 担心运动时大量血液流至肌肉，影响供应胎盘及胎儿的血流不足，导致缺氧：根据临床研究发现，虽然中度运动会增加子宫内的血流阻力，但不会影响脐带循环，不会增加胎儿缺氧及窘迫的发生。
2. 担心运动时的能量消耗，影响胎儿成长：有报告，太剧烈的运动，会造成新生儿体重降低，但中等强度运动不会，且有运动的孕妇，生出的小孩，身体脂肪量较低。另外，没有运动的孕妇，容易有妊娠糖尿病，较会有胎儿体重过重发生，造成生产及新生儿的并发症。
3. 担心运动时体温升高，造成胎儿发育异常：研究显示，孕妇会有“热保护机制”，靠着增加血液循环及出汗，来避免身体体温上升过度，抵消母体过热对早期胎儿发育的不良影响，确保胎儿稳定生长环境。
4. 担心运动造成子宫收缩，早产发生：研究显示，适度运动并没有增加早期子宫收缩及早产的风险。
 
怀孕期间运动的好处
已有很多研究显示，对于健康孕妇，怀孕期间如有规律运动，能有许多益处，包括下列可能好处：
1. 减少怀孕期间的体重过度增加。
2. 减少妊娠糖尿病、妊娠高血压，早产，静脉曲张及深层静脉血栓等发生。
3. 缩短生产过程，减少生产并发症，及降低剖腹生产率。
4. 心理方面的益处，包括减轻疲劳，降低焦虑、压力及忧郁等发生。
5. 减少产后出现妊娠纹，因为有运动的妇女有较少的皮下脂肪和有较强壮的肌肉。
6. 孕中有运动习惯，产后容易持续运动，加速产后身体恢复。
 
早在十八世纪，就有关于怀孕期间作息活动的建议，当时主要是根据传统观念及规范而定，大部分建议怀孕期间减少活动。进入到二十世纪之后，越来越多的科学研究论文发表，提供更现代及更科学的根据，众多欧美国家，包括：美国、加拿大、澳大利亚，英国、法国、丹麦、挪威，西班牙及日本等国，都针对怀孕期间的活动及运动，制定准则及做出建议，针对健康孕妇，大都建议要有规律适度的运动。运动对怀孕有益，但并非所有人都适合运动，也不是所有运动都适合怀孕妇女作，做好评估才能安全的运动。
 
那些孕妇不宜运动
1. 当孕妇有下列情况，绝对不适合运动：子宫颈闭锁不全，三胞胎或三胞胎以上的多胞胎，早期子宫收缩，早期破水，怀孕第二期或第三期的阴道持续出血，严重胎儿生长迟滞，前置胎盘28周以后，怀孕期间的高血压，控制不好的内科疾病（甲状腺疾病，心血管疾病，第一型糖尿病，肺部疾病等）。
2. 当孕妇有下列情况，相对不适合运动，如要运动，应经医师评估及充分讨论：有流产或早产病史，双胞胎28周以后，贫血（Hb < 100g/L），营养不良或进食问题，有轻中度的心血管或肺部疾病等。
3. 怀孕期间运动，当遇到下列情况，影考虑停止运动，当情况改善，再恢复运动：晕眩，头痛，胸痛，出血，呼吸困难，肌肉无力，子宫收缩，胎动减少，漏出羊水及小腿肌肉疼痛水肿（须排除静脉栓塞）等。
 
怀孕期间的怎么运动
根据孕妇的身体状况，在选择运动及强度需有所不同：
1. 何种运动适合孕妇作：
l 一般建议有氧运动，可达到增加心肺功能及控制体重增加。
l 加上无氧肌力训练更好，可增加全身肌肉力量，改善姿势，减少腰酸背痛，帮助生产，但须注意不要过度伸展。
l 应避免容易跌倒或撞击子宫的运动，如竞争性的运动（短跑），或身体接触的球类（篮球或足球）。
l 怀孕16周以后应避免身体平躺的运动或训练，如平躺举重或瑜珈。
l 考虑较容易取得及可长期执行的运动，如散步，快走，慢跑或飞轮。
l 较无负重的有氧运动更适合孕妇，如踩飞轮或游泳。
l 瑜珈，太极及气功也可作。
2. 强度：
l 大部分都建议中等强度的运动，即运动时的心跳达到个人最高心跳速率的50至70%。
l 也可根据孕妇年纪作调整，20岁以下140~155；20至30岁135~150；30至40岁130~145；40岁以上125~140。
l 过度肥胖的孕妇，运动时的心跳速率，可在下修，20至30岁110~131；30至40岁108~127。
l 如无心跳表测心跳速率，可根据运动时讲话的难易度来评估，理想适合孕妇运动的强度是运动时讲话“感觉有一点点困难”的程度。
l 以前是运动员或从事高难度运动者，怀孕后应将运动种类、强度及频率，作适当调整，一般强度可减少20~30%。
3. 频率及时间：
l 怀孕前无运动习惯者，可由每周三次15分钟轻中度运动，逐渐增加到每周四次30分钟运动。
l 怀孕前有运动习惯者，可延续原来运动方式，或每周四次30分钟以上运动中度或剧烈运动。
l 每次运动前应作暖身运动，运动后应作和缓伸展动作。
 
怀孕期间运动的注意事项
1. 运动前后要补充适当的饮食：可确保运动效能，及提供胎儿健康成长。
2. 运动前中后要摄取足够水分：补充流失的水分，并避免母亲身体过热产生。
3. 选择安全的运动及场所，避免跌倒或撞击，避免在湿热的环境运动。
4. 与医师及运动指导员讨论，选择适合的运动计划。
5. 随时调整运动强度，不要过度勉强。
6. 运动时穿着宽松、舒适的衣服，保持心情愉快。
7. 运动前排空膀胱。

即使很多的科学证据显示，怀孕期间运动，提供多重好处。然而，并非所有孕妇都能确实规律运动，因素很多，包括：正确信息获得，个人的信念，长辈同侪的压力，明星媒体的影响，及运动设施场地获得的容易程度等。

破除旧观念，需要先获得正确最新的信息，并坚定对的信念，确实执行。怀孕期间的运动，对一些长辈而言，是有别于他们根深蒂固的想法，对于长辈的好意，我们应该提供他们正确的新信息，充分沟通，达到长辈获得知识，我们获得健康的双赢效果。
作好个人怀孕状况评估，配合专家建议选择适合自己的运动种类及调整运动的强度，并持续坚持孕期适度的运动，不仅对母亲、胎儿及怀孕有益处，也间接放松心情，让孕妇整个孕期都能安全舒适的度过，达到「健康妈妈，健康宝宝」的最终目标。

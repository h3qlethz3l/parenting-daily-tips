# 锦旗故事 | 柳州市工人医院助残肢痛患者重返正常生活

> 更新时间：2026-09-11 (UTC+8)

**精准治疗**

**让残肢痛患者重返正常生活**

// 疼痛科 //

近日，饱受右上肢残端剧痛困扰的患者莫先生（化姓），在康复出院当天将一面印有“医术精明治顽疾，仁心仁术惠众生”的锦旗送到疼痛科医师田永正及疼痛科全体医护人员手中，感谢疼痛科团队以精准诊疗解除顽疾，让他重返正常生活。

PART.01

**意外致残添剧痛，生活康复受困扰**

半年前，莫先生在工作中遭遇机器压伤，导致右上肢严重毁损，经柳州市工人医院创伤外科紧急抢救后实施右上肢截断手术，生命得以挽救，残端创面愈合良好。

术后，创伤带来的长期影响开始显现，莫先生残端逐渐出现针刺样疼痛，伴随明显烧灼感与麻木感，不仅严重影响生活质量，更阻碍后续康复锻炼。近期症状持续加重，剧烈刺痛、辣痛、灼痛、麻痛感反复发作，夜间无法安睡，生活质量严重下降。这也成为他此次前来疼痛科寻求进一步帮助的主要原因。

疼痛科主任卢建华接诊后，详细评估病情，以残肢痛将其收入院系统治疗。卢建华介绍，残肢痛多见于高位截肢或关节离断术后，属外周神经病理性疼痛，常表现为跳痛、刺痛、灼痛、蚁爬感、电击痛等，疼痛可放射至周边部位，常规治疗难度较大。

PART.02

**精准微创综合治，一周康复解顽痛**

结合患者手术史与疼痛特点，疼痛科团队制定个体化综合治疗方案，以药物规范治疗+银质针松解+靶点神经根脉冲射频的联合模式，实现精准镇痛、长效调控。

治疗中，团队先在臂丛神经阻滞下，以密集型银质针对残端进行松解，可逆性损毁异常神经末梢、阻断疼痛传导，同时通过温热效应改善局部血运、消除无菌性炎症、松解粘连组织，修复软组织环境。随后在可视化超声引导下，对颈6、颈7责任靶点神经根实施脉冲射频调控，从根源调节神经功能、抑制疼痛信号传递，实现神经病理性疼痛的长效管理。

治疗期间，护理团队全程悉心照护，指导康复锻炼、疏导焦虑情绪。经一周系统治疗，莫先生残端刺痛、灼痛、麻木感缓解，顺利康复出院。

PART.03

**疼痛科：让复杂疼痛不再难治**

医院疼痛科作为治疗各类慢性疼痛的专业科室，在神经病理性疼痛，如**残肢痛、幻肢痛、带状疱疹后神经痛**等复杂、顽固性疼痛领域积累了丰富的临床经验。通过银质针、神经阻滞、神经射频等微创介入技术，结合药物调理、物理治疗等综合手段，为患者提供从评估到治疗的全流程疼痛管理方案。

一面锦旗，一份信任，一份责任。疼痛科将继续秉承专业、负责的态度，用精准的技术和温暖的服务，帮助更多患者远离疼痛困扰，重拾健康生活。
